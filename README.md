# Screen Lighting Control (SLC)

A tiny, extremely fast Windows utility that controls how bright your screens are and what color light they give off.
It combines the ideas of **Dimmer** (dimming below the hardware minimum) and **f.lux** (automatic warmth), with a
hybrid pipeline: hardware backlight, then gamma, then overlay.

Status: in development. See [`docs/PRODUCT.md`](docs/PRODUCT.md) for the spec and [`docs/DEVELOPMENT.md`](docs/DEVELOPMENT.md) to build.
